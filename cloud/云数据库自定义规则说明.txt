一、在云开发控制台哪里改
  微信开发者工具 → 云开发 → 数据库 → 选中集合（如 kitchen_dishes）→「权限设置」→ 选「自定义安全规则」→ 粘贴下方规则 → 保存。

二、当前小程序客户端直读写库，适合家庭内网测试的规则（读写放开，与代码现状一致）
  集合 kitchen_dishes、kitchen_accounts 均可使用：

  {
    "read": true,
    "write": true
  }

  说明：所有用户可读可写，仅适合可信环境。若出现「能写云端但本地餐桌不同步」等，多半是规则拒绝 write，可先用上式验证。

三、稍严：所有人可读，仅创建者可写（需每条记录带 _openid 且为当前用户创建）
  {
    "read": true,
    "write": "doc._openid == auth.openid"
  }

  注意：本项目账号为自建用户名密码，文档未必带 _openid，用此规则可能导致客户端 set 失败，需改为云函数用管理员权限写库，或写入时在 data 里带上当前用户 openid 字段并在规则里比较该字段。

四、建议索引（控制台 → 集合 → 索引管理）
  kitchen_accounts：username（唯一）、email（唯一）

五、后台如何改数据
  同上路径「数据库」→ 选中集合 → 可浏览记录、点某条编辑字段、或「导入」JSON。正式运营更建议用云函数 + 管理端，避免控制台误删。
